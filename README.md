# Портфель — личный дашборд инвестиций для ИИ-агента

Навык для агентов **DeepSeek Harness** и **Claude Code**. Вы пишете агенту обычными словами — «настрой мой портфель»,
«обнови», «добавь вкладку с целью» — и он собирает у вас на компьютере страницу с портфелем:

- стоимость и изменение за день, прибыль за всё время, годовая доходность с учётом пополнений (XIRR);
- сравнение с индексами Мосбиржи (полной доходности, гособлигаций, корпоративных облигаций);
- состав по бумагам, видам и отраслям, карточка бумаги;
- дивиденды и купоны: история до и после налога, прогноз на 12 месяцев;
- лента операций с поиском и фильтрами; светлая и тёмная тема, нормальный вид на телефоне.

Это **не сервис**: сервера нет, страница — файл у вас в папке. Наружу уходят только запросы цен и индексов к Мосбирже
и курсов к ЦБ (и загрузка шрифтов страницы). Ваши операции и суммы остаются на компьютере — кроме того, что вы
сами показываете своему агенту.

Не является индивидуальной инвестиционной рекомендацией: навык считает и показывает, но не советует, что покупать
или продавать.

## Что нужно

- **Node.js 18 или новее** — проверить: `node --version`. Нет — поставьте версию LTS с [nodejs.org](https://nodejs.org).
- Агент: DeepSeek Harness (с ключом DeepSeek в настройках агента) или Claude Code.
- Для своего портфеля — операции из одного или нескольких источников:
  - выгрузка **Snowball Income** (CSV);
  - **Т-Инвестиции** через официальный API — нужен токен **только на чтение** (readonly): настройки Т-Инвестиций
    (www.tbank.ru/invest/settings/) → токены T-Invest API → выпустить токен с доступом только на чтение. Полный доступ
    навыку не нужен. Токен держите в переменной окружения `TINVEST_TOKEN` или в `settings.json` и никому не показывайте;
  - брокерский отчёт **БКС** в формате `.xlsx`;
  - отчёт брокера **Сбербанка** в HTML;
  - выгрузка **«Интеллектуального инвестора»** (`.xlsx`);
  - ручной шаблон `skills/portfolio/sample/шаблон-операций.csv` — для других брокеров и поправок.

  Для пробы ничего не нужно: в навыке есть выдуманный тестовый портфель.

## Установка

Скачайте репозиторий (кнопка Code → Download ZIP на GitHub, распакуйте) или `git clone`.

### DeepSeek Harness

Скопируйте папку навыка `skills/portfolio` в `~/.agents/skills/` или в `~/.dsh/skills/`. Проще всего — из папки
репозитория в терминале:

```
./install.sh
```

Скрипт спросит, в какой каталог ставить, скопирует навык и запустит его проверки. Если навык уже стоит, старую
копию он не удалит, а отложит в `~/.portfolio-skill-old/`. Вручную:

```
mkdir -p ~/.agents/skills && cp -R skills/portfolio ~/.agents/skills/
```

Навык должен лежать именно так: `~/.agents/skills/portfolio/SKILL.md` (не глубже). Перезапустите агента.

### Claude Code

Вариант 1 — как навык: `./install.sh` и выбрать `~/.claude/skills`, или вручную

```
mkdir -p ~/.claude/skills && cp -R skills/portfolio ~/.claude/skills/
```

Вариант 2 — как плагин прямо с GitHub (репозиторий сам служит каталогом плагинов). В Claude Code:

```
/plugin marketplace add PiedPiperMoney/portfolio-skill
/plugin install portfolio@portfolio-skill
```

Навык появится как `/portfolio:portfolio`;
звать его командой не обязательно — агент возьмёт навык сам, когда вы попросите про портфель.

## Первый запуск — на тестовом портфеле

1. Откройте агента в любой папке и напишите: **«покажи дашборд портфеля на тестовом портфеле»**.
2. Агент спросит, где держать файлы (по умолчанию `~/Мой портфель`), скопирует туда тестовую выгрузку и настройки,
   соберёт данные (первый раз — минута-две: качаются цены с Мосбиржи) и откроет страницу в браузере.
3. Посмотрите разделы: Обзор, Активы, Избранное, Доходность, Выплаты, Операции, Данные.

Тестовый портфель выдуман: пять акций Мосбиржи из разных отраслей и одна ОФЗ, сделки, дивиденды, купоны,
налоги и комиссии за 2021–2026 годы, немного юаней на счёте.

## Свой портфель

1. Подготовьте операции: выгрузку Snowball (CSV), токен Т-Инвестиций только на чтение, отчёт брокера БКС (.xlsx)
   или Сбербанка (HTML), выгрузку «Интеллектуального инвестора» — что есть. Несколько источников можно сразу:
   одинаковые операции из двух источников по одному счёту навык посчитает один раз, переводы бумаг между своими
   счетами не считает покупкой и продажей. Если счетов несколько, на странице есть переключатель:
   «Все счета», брокер или отдельный счёт — все разделы показывают выбранный портфель. Несколько портфелей
   в Snowball — выгрузите по файлу на каждый.
2. Напишите агенту: **«настрой мой портфель, выгрузка Snowball лежит в Загрузках»** (или «подключи Т-Инвестиции»,
   «вот отчёт БКС»). Агент положит файл в вашу
   папку, спросит название и сколько свободных денег на счёте, соберёт страницу и расскажет итог: сколько
   операций, бумаг, стоимость, доходность и что не сошлось.
3. Дальше:
   - **«обнови портфель»** — после новой выгрузки или просто чтобы подтянуть цены; агент скажет, что изменилось;
   - **«добавь вкладку с целью 10 млн к 2035 году»**, «покажи дивиденды по месяцам столбиками», «сделай
     заголовок крупнее» — агент дорабатывает страницу. Ваши доработки лежат в `custom.js` и `custom.css` у вас
     в папке и не пропадают при обновлении навыка. После каждой правки агент запускает проверки расчётов.

## Что в папке портфеля

| Файл | Что это |
|---|---|
| `index.html` | дашборд — открывается двойным щелчком, без сервера |
| `settings.json` | название, источники операций, деньги на счёте, избранное |
| `reports/` | выгрузки и отчёты брокеров |
| `dashboard-data.js`, `report.json`, `.cache/` | собранные данные, итог сборки, скачанные цены |
| `custom.js`, `custom.css` | ваши доработки |

## Как считается

- **Стоимость** — бумаги по цене закрытия Мосбиржи (облигации — % от номинала × номинал + НКД) плюс деньги
  на счёте из настроек. В часы торгов страница сама обновляет цены раз в минуту.
- **Прибыль за всё время** — стоимость + продажи − покупки − комиссии и налоги + выплаты после налога.
  Пополнения доходностью не считаются.
- **XIRR** — годовая доходность с учётом того, когда и сколько вкладывалось.
- **Сравнение с индексом** — «что было бы, если те же деньги в те же дни вкладывать в индекс».
- **Прогноз выплат** — по вашим выплатам за прошлые 12 месяцев (купоны облигаций — по расписанию Мосбиржи);
  это оценка, а не объявленные дивиденды.

## Ограничения

- **Т-Инвестиции** — только токен на чтение; нужен интернет; переводы типов операций сверены с документацией
  T-Invest API, но проверены на выдуманных ответах, а не на живом счёте.
- **БКС** — только `.xlsx`; старый `.xls` нужно пересохранить в `.xlsx` (Excel, Numbers, LibreOffice).
- **Сбербанк** — формат HTML-отчёта проверен только на образце, собранном по разделам отчёта брокера. Что не
  распознано, навык не выбрасывает молча, а показывает в `report.json` → `unknown` (без сумм) — такую строку можно
  прислать разработчику.
- Сделки с фьючерсами и опционами в позиции не входят: результат срочного рынка показан вариационной маржой в ленте.
- Бумаги, пришедшие переводом от неподключённого брокера, без цены покупки считаются по нулевой цене — допишите
  покупку в шаблон CSV или подключите тот счёт.
- **Американские и другие иностранные бумаги** — по ценам ваших собственных сделок × курс ЦБ: у Мосбиржи их цен
  нет, стоимость приблизительная.
- **Прогноз выплат** — по прошлым 12 месяцам, без объявленных и ожидаемых дивидендов.
- Деньги на счёте не считаются из операций — их задаёте вы в настройках.
- Не инвестиционный совет.

## Для разработчика

- `skills/portfolio/engine/` — сборка данных на Node.js без зависимостей (`sources/` — источники операций,
  у каждого таблица соответствий «тип операции → событие» в начале файла; `lib/` — мини-читатели xlsx и HTML;
  `merge.mjs` — объединение источников, дубли, переводы и конвертации); `dashboard/` — шаблон страницы
  (правила доработки — `dashboard/ПРАВИЛА.md`); `sample/` — тестовый портфель; `references/` — сценарии для агента.
- Проверки без сети: `node skills/portfolio/tests/run.mjs` (расчёт — `model.test.mjs`; источники на выдуманных
  образцах из `tests/fixtures/` — `sources.test.mjs`; разбивка по брокерам и счетам с переводами — `accounts.test.mjs`).
