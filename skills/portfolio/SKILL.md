# Портфель: дашборд инвестиций у человека на компьютере

Навык собирает человеку страницу с его портфелем: стоимость, прибыль, годовая доходность (XIRR), сравнение
с индексом, состав по бумагам и отраслям, выплаты и прогноз на 12 месяцев, лента операций. Всё лежит в папке
человека и открывается в браузере. Сервера нет.

**Папка навыка** — та, где лежит этот `SKILL.md`. Ниже `<навык>` — её полный путь, `<папка>` — рабочая папка человека.

## Что нужно

- Node.js 18 или новее: `node --version`. Нет Node или версия старше — попроси человека поставить Node.js с
  nodejs.org (версию LTS) и вернуться. Сам ничего системного не ставь.
- Интернет — для цен Мосбиржи и курсов ЦБ (без сети сборка работает по кэшу с флагом `--offline`).
- Операции — один или несколько источников (`settings.json` → `sources[]`, у каждого — `type` и `account`,
  необязательно `broker` — под каким брокером показать счёт; без него — по типу источника, у Snowball, «Интеллектуального
  инвестора» и CSV — сам счёт). Если счетов больше одного, на странице есть переключатель «Все счета → брокер →
  счёт»; деньги на счёте (`cash[]`) с полем `account` видны и в портфеле этого счёта, без него —
  только во «Все счета». Как назвать счета — [настройка.md](references/настройка.md), шаг 3:

  | `type` | Что это | Ограничения |
  |---|---|---|
  | `snowball` | выгрузка Snowball (CSV) | — |
  | `tinvest` | Т-Инвестиции по официальному API | нужен токен **только на чтение**; нужен интернет |
  | `bcs` | брокерский отчёт БКС | только `.xlsx`; старый `.xls` — пересохранить (см. настройку) |
  | `sber` | отчёт брокера Сбербанка в HTML | формат проверен **только на образце** — нераспознанное честно показать |
  | `intelinvest` | выгрузка «Интеллектуального инвестора» (`.xlsx`, лист «Сделки») | — |
  | `csv` | ручной шаблон `sample/шаблон-операций.csv` | для остальных брокеров и поправок |

  Как получить файл или токен у каждого — [references/настройка.md](references/настройка.md), шаг 2. Брокера нет
  в списке — предложи шаблон CSV или выгрузку Snowball, ничего не выдумывай про формат его отчёта.

## Рабочая папка человека

Спроси, где держать портфель. Если человеку всё равно — предложи `~/Мой портфель`. В ней будут:

| Файл | Что это | Кто меняет |
|---|---|---|
| `reports/` | выгрузки и отчёты брокеров | человек кладёт, агент копирует |
| `settings.json` | название, источники, деньги на счёте, избранное | агент по просьбе человека |
| `index.html`, `styles.css`, `js/` | страница дашборда (копия шаблона навыка) | агент при доработке |
| `custom.js`, `custom.css` | свои доработки человека | агент при доработке; обновление навыка не трогает |
| `dashboard-data.js` | данные для страницы | только `engine/build.mjs` |
| `report.json` | итог последней сборки: операции, стоимость, предупреждения | только `engine/build.mjs` |
| `.cache/` | скачанные цены и курсы | только `engine/build.mjs` |

## Три сценария

Перед работой прочитай целиком файл своего сценария.

1. **Настройка** — первый раз, папки ещё нет или в ней нет `settings.json`: [references/настройка.md](references/настройка.md).
   Если человек хочет сначала посмотреть — там же запуск на тестовом портфеле (`sample/`).
2. **Обновление** — новая выгрузка или просьба «обнови»: [references/обновление.md](references/обновление.md).
3. **Доработка** — вкладка, график, цель, подсветка, другой вид: [references/доработка.md](references/доработка.md)
   и обязательно [dashboard/ПРАВИЛА.md](dashboard/ПРАВИЛА.md).

Сборка во всех сценариях одна:

```
node "<навык>/engine/build.mjs" --workdir "<папка>"
```

Ярлык на рабочем столе, чтобы открывать дашборд без агента (человек просит «сделай ярлык / значок») —
`node "<навык>/engine/shortcut.mjs" --workdir "<папка>"`, подробно — [настройка.md](references/настройка.md), шаг 6.

## Правила

1. **Личные данные никуда не отправлять.** Выгрузки и отчёты, `settings.json`, `dashboard-data.js`, `report.json` остаются
   в папке человека. Токен Т-Инвестиций — секрет: человек вписывает его сам в `settings.json` (`sources[].token`)
   или в переменную окружения `TINVEST_TOKEN`; прислал в чат — запиши в `settings.json` и больше нигде не повторяй
   (ни в ответах, ни в командах, ни в других файлах). Наружу ходят только запросы цен и индексов к Мосбирже
   (iss.moex.com), курсов ЦБ (cbr.ru, в странице — зеркало курсов ЦБ cbr-xml-daily.ru) и, если подключены
   Т-Инвестиции, запросы к API Т-Банка (invest-public-api.tbank.ru) с токеном человека — их делают `engine/` и сама страница; ещё страница
   грузит шрифты Google Fonts (без данных человека). Не загружай файлы человека на сайты, в чаты, в облако, в GitHub,
   не вставляй его суммы и тикеры в поисковые запросы.
2. **Без инвестиционных советов.** Показывай и объясняй цифры, но не советуй купить, продать, держать,
   «докупить на просадке», не оценивай бумаги как хорошие или плохие. На такой вопрос отвечай, что навык
   считает и показывает, а решение — за человеком. Строка «не является индивидуальной инвестиционной
   рекомендацией» внизу страницы остаётся.
3. **Не трогать расчёт сравнения с индексом и стоимости**: `dashboard/js/benchmark.js` (`bench`, `compare`,
   `flowsSum`, `twr`), `applyQuotes` в `js/live.js`, `recompute` в `js/core.js`, формат `dashboard-data.js`
   и всё в `engine/`. Подробно — [dashboard/ПРАВИЛА.md](dashboard/ПРАВИЛА.md), раздел «Что трогать нельзя».
4. **После любой правки — проверки:**
   ```
   node "<навык>/tests/run.mjs" --dashboard "<папка>"
   ```
   Должно закончиться строкой «ВСЁ ПРОШЛО». Не прошло — исправь до того, как показывать человеку. Проверки
   идут без сети: расчёт на маленьком портфеле с ответами, посчитанными вручную, сравнение с индексом тем же
   кодом, что в странице человека, синтаксис всех скриптов страницы и `custom.js`.
5. **Цифры — только из `report.json` и страницы.** Не пересчитывай стоимость и доходность в уме и не округляй
   «на глаз»; называя число, говори, на какую дату оно и что в него входит.
6. **Говори с человеком просто:** без названий файлов и функций там, где можно без них; предупреждения из
   `report.json` пересказывай своими словами и говори, что с ними сделать.
